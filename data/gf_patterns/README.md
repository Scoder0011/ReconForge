# GF patterns

These files are intentionally minimal starter patterns for a first-run local recon workflow.
They are not a complete gf-patterns library and are meant to be replaced or supplemented with a larger public set later.

Common sources for deeper coverage include the public `gf-patterns` repositories and community pattern packs.

The default local scanner expects these files to be present in the repo and copies them into a user gf pattern directory when the stage runs.
